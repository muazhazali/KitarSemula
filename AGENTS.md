# AGENTS.md

KitarSemula.app — Malaysia recycling center directory. Next.js 16 (App Router) + React 19 + Tailwind v4 + shadcn/ui, packaged with pnpm 11+ (lockfile v9). Node 20.18+.

## Commands

- `pnpm dev` / `pnpm build` / `pnpm start` — dev (Turbopack), production build, serve build.
- `pnpm preview` / `pnpm deploy` — build via `opennextjs-cloudflare` and run locally / deploy to Cloudflare Workers.
- `pnpm cf-typegen` — regenerate `worker-configuration.d.ts` from `wrangler.jsonc`. Required before typechecking after any binding change; the file is generated and gitignored.
- `pnpm lint` — ESLint flat config (`eslint.config.mjs`, `eslint-config-next` + `eslint-config-prettier`).
- `pnpm lint:fix` / `pnpm format` / `pnpm format:check` — autofix and Prettier.
- **No test suite exists.** Do not invent test commands.
- Typecheck manually: `pnpm exec tsc --noEmit` (there is no `typecheck` script).
- Regenerate seed data: `pnpm dlx tsx scripts/convert-csv.ts` (writes `lib/seed-data.ts` + `lib/center-slugs.ts`).
- Seed D1: `pnpm seed:local` / `pnpm seed:remote` (generate SQL then execute via wrangler).
- Apply migrations: `pnpm exec wrangler d1 migrations apply kitarsemula-db --local|--remote`.

## Critical gotchas

- **Build ignores TypeScript errors.** `next.config.mjs` sets `typescript.ignoreBuildErrors: true`; `pnpm build` passing does NOT mean code typechecks. Always run `pnpm exec tsc --noEmit`.
- **D1 is the runtime source of truth for centers and votes.** `lib/db/centers.ts` owns search + lookup; `lib/db/votes.ts` owns vote persistence (one vote per IP per center via `votes` PK). `lib/seed-data.ts` is now seed input only — it is not imported by app code. `lib/utils/centers.ts` holds pure helpers (`isOpenNow`, `getDistanceKm`, `formatDistance`, `getMarkerColor`, `getStatusLabel`, `getTodayHours`) and must stay client-safe: never import D1 or seed data into it (`center-card.tsx` and `recycling-map.tsx` are client components).
- **`generateStaticParams` reads `lib/center-slugs.ts`, not D1.** The D1 binding is unavailable at build time, so the slug list is generated by `scripts/convert-csv.ts`. Center pages are ISR (`revalidate = 300`) and fetch the full record from D1 per request.
- **Photos: 1 per center, ≤1 MB.** The cap is enforced atomically in `lib/db/photos.ts#insertPhoto` (D1 `UNIQUE (center_slug, slot)` + `slot < 1`); the API returns 409 when full. Bytes live in R2 (`PHOTOS` binding), metadata in D1. Limits live in `lib/types.ts` (`MAX_PHOTOS_PER_CENTER`, `MAX_PHOTO_BYTES`) — don't hardcode them.
- **The photo proxy route is `/api/photos/[id]`** (keyed by photo id), but `resolvePhotoUrl` points at `PHOTO_PUBLIC_BASE_URL/<r2Key>` when that env var is set. Don't change one without the other.
- **Public photo delete was intentionally not implemented.** Don't add an unauthenticated DELETE.
- **Abuse protection fails closed in production.** `lib/rate-limit.ts#checkRateLimit` and `lib/turnstile.ts#verifyTurnstile` allow requests when their binding/secret is missing only when `NODE_ENV !== 'production'`. In production a missing binding/secret returns 429/403. This means **a missing `TURNSTILE_SECRET_KEY` or rate-limit binding breaks uploads in prod by design** — verify config after deploy.
- **Turnstile validation checks action AND hostname, not just `success`.** `verifyTurnstile` requires `data.action === expectedAction` and (when `TURNSTILE_HOSTNAMES` is set) an approved `hostname`. The widget must render with a matching `action` (`TURNSTILE_ACTION_PHOTO_UPLOAD` in `lib/env.ts`). Adding a new protected surface means adding an action constant and passing it to the widget.
- **`TURNSTILE_HOSTNAMES` must list exact frontend hostnames, not widget domain entries.** Siteverify returns the hostname of the page where the challenge was solved (e.g. `kitarsemula.muaz.app`), not the widget's registered domain (`muaz.app`). Listing only the root domain rejects every upload. It lives in `wrangler.jsonc` `vars` (non-secret) and excludes `localhost`. The widget registers `127.0.0.1, localhost, muaz.app`; `muaz.app` covers subdomains, which is why the custom domain works while bare `*.workers.dev` does not.
- **`NEXT_PUBLIC_TURNSTILE_SITE_KEY` is inlined at build time.** It must be set in the _build_ environment (`pnpm deploy`), not as a Worker runtime var, or the widget won't render and uploads will 403 against the server secret.
- **`public/_headers` uses `#` comments, not `/* */`.** A stray `/*` block makes `wrangler deploy` fail with `Invalid _headers configuration: Expected a colon-separated header pair`. `_headers` only applies to static assets; SSR/API headers come from `middleware.ts`.
- **Security headers live in `middleware.ts`.** `public/_headers` only applies to static assets, never to SSR/API responses. CSP keeps `'unsafe-inline'` in `script-src` because Next emits inline bootstrap scripts. Keep both files in sync if you change the policy.
- **`nodeLinker: hoisted` in `pnpm-workspace.yaml` is required, not a preference.** OpenNext recreates pnpm's symlinked `node_modules` with `fs.symlinkSync`, which Windows blocks (`EPERM`) without Developer Mode. Removing this line reintroduces a hard build failure. pnpm 11 ignores `.npmrc`, so the setting must live in `pnpm-workspace.yaml`.
- **`open-next.config.ts` is required** at the repo root; `opennextjs-cloudflare` refuses to build without it.
- **`wrangler deploy` re-runs the OpenNext build.** You cannot skip `pnpm exec opennextjs-cloudflare build`; a deploy with a stale/absent `.open-next/worker.js` silently ships broken code. Delete `.next` and `.open-next` if artifacts look inconsistent.
- **`worker-configuration.d.ts` is generated** (`pnpm cf-typegen`) and gitignored. It defines `D1Database`/`R2Bucket`/`RateLimit`; regenerate after editing `wrangler.jsonc` or typecheck breaks. It also makes `res.json()` return `unknown`, so fetch call sites must cast.
- **Route handler `params` are async (Next 15+).** Type is `{ params: Promise<{ slug: string }> }` and every handler must `await params` first.
- **shadcn style `base-nova` uses Base UI (`@base-ui/react`), not Radix.** All `components/ui/*` import primitives from `@base-ui/react/*` (`merge-props`, `use-render`, etc.). Don't add Radix-based snippets.
- `next.config.mjs` sets `images.unoptimized: true` — don't add `next/image` features that require the optimizer.
- **Dependency overrides live in `pnpm-workspace.yaml`, not `package.json`.** pnpm 11+ ignores `pnpm.overrides`; the `hono` pin and `postcss` security pin are there — edit them there.
- **`lib/seed-data.ts` is generated** by `scripts/convert-csv.ts` from `recycling_centres_malaysia_v2_enriched.csv` (repo root). Regenerate rather than hand-editing bulk rows. `tsx` is NOT a dependency — run via `pnpm dlx tsx`. The CSV is currently untracked.
- **`scripts/seed-d1.ts` writes UTF-8 without BOM** to `.wrangler/seed.sql`. Don't redirect it with PowerShell `>` (produces UTF-16, which wrangler rejects). Remote D1 also rejects `BEGIN TRANSACTION` in seed files.
- `next-env.d.ts` is generated by Next; don't edit it.
- Pre-commit (husky + lint-staged) runs Prettier + `eslint --fix` on staged files; `prepare` wires hooks on `pnpm install` when `.git` exists.

## Structure

- `app/` — App Router.
  - `app/api/centers/route.ts` — search (`GET`, parses query params into `SearchParams`, delegates to `lib/db/centers.ts#searchCenters`).
  - `app/api/centers/[slug]/` — `route.ts` (single center), `vote/` (D1), `photos/` (R2+D1).
  - `app/api/photos/[id]/route.ts` — R2 proxy used when no public photo domain is set.
  - `app/center/[slug]/page.tsx` — server component; `generateStaticParams` over `lib/center-slugs.ts`, fetches from D1 at request time, emits JSON-LD, renders client detail.
  - `app/page.tsx` → `components/home/home-client.tsx` (map + sidebar shell).
- `lib/` — domain logic.
  - `lib/types.ts` — shared types AND runtime constants (`RECYCLABLE_CATEGORIES`, `MALAYSIA_STATES`). Import constants from here; don't hardcode strings.
  - `lib/seed-data.ts` / `lib/center-slugs.ts` — generated seed input (see `scripts/`).
  - `lib/utils/centers.ts` — pure, client-safe search helpers: open-now/haversine/formatting. Reuse; don't reimplement.
  - `lib/db/centers.ts` — D1 search + lookup (`rowToCenter`, `searchCenters`, `getCenterBySlug`, `getAllSlugs`).
  - `lib/db/votes.ts` — D1 vote persistence (`recordVote`, `getVoteCounts`).
  - `lib/db/client.ts` — `getAppEnv()` returns Cloudflare bindings or `null` when unavailable (routes return 503, never throw).
  - `lib/db/photos.ts` — D1 photo metadata + `resolvePhotoUrl`; `migrations/` holds SQL.
  - `lib/turnstile.ts` / `lib/rate-limit.ts` — abuse protection (fail closed in production).
  - `lib/env.ts` — `isProduction()`, `turnstileSiteKey()`.
- `middleware.ts` — baseline security headers (CSP etc.) for SSR/API responses.
- `components/` — feature-grouped (`home/`, `centers/`, `map/`, `search/`, `providers/`); `components/ui/` is shadcn-generated.
- `scripts/` — `convert-csv.ts` (CSV → seed + slugs), `seed-d1.ts` (seed → SQL).

## Conventions

- Path alias `@/*` → repo root (`tsconfig.json` paths, `components.json` aliases). `lib/utils.ts` exports `cn()`.
- Tailwind v4 via `@tailwindcss/postcss`: NO `tailwind.config.js`; theme/CSS variables live in `app/globals.css`. Add UI via `pnpm dlx shadcn@latest add <name>`.
- Opening-hours strings use the en-dash `–` (U+2013), e.g. `8:00 AM – 12:00 PM`. `isOpenNow` splits on `–`, not `-`; preserve when editing hours.
- Leaflet/react-leaflet is client-only: map components are default-exported and dynamically imported with `{ ssr: false }` (`home-client.tsx`, `center-detail-client.tsx`). Never render Leaflet during SSR.
- `@vercel/analytics` was removed: it 404s on Workers (`/_vercel/insights/script.js`). Don't re-add it; use Cloudflare Web Analytics instead.
